# OmniGraph I/O [omni.graph.io]

This extension is deprecated. It previously implemented 4 OmniGraph nodes, these nodes have been moved to the omni.graph.nodes extension.
* ImportUSDPrims - Deprecated, use omni.graph.nodes.ReadPrim suite of nodes instead for this functionality.
* ExportUSDPrims - Deprecated, use omni.graph.nodes.WritePrim suite of nodes instead for this functionality.
* BundleToUSDA - moved to omni.graph.nodes
* TransformBundle - moved to omni.graph.nodes

This extension should no longer be used. Update any dependencies to reference omni.graph.nodes instead.
