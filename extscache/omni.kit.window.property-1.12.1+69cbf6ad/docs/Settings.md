# Settings

## Settings the extension provides:

### "/ext/omni.kit.window.property/checkboxAlignment"
- default is "left"
- checkboxAlignment can be "left" or "right"

### "/ext/omni.kit.window.property/labelAlignment"
- default is "left"
- labelAlignment can be "left" or "right"

### "/ext/omni.kit.window.property/enableSearch"
- default is true
- show/hides the "Search" option when true/false

## Settings the extension uses from other extensions:

### "/persistent/app/window/uiStyle"
- default is "NvidiaDark"
- gets which light/dark theme kit is using. Not widely supported

### "/persistent/app/window/useDefaultStyle"
- default is "false"
- use default UI styling or the property window styling.
