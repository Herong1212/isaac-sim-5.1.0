# Settings

## Settings Provided by the Extension
### exts."omni.kit.viewport.menubar.render".visible
   - **Default Value**: true
   - **Description**: Determines if the render menu bar is visible.

### exts."omni.kit.viewport.menubar.render".order
   - **Default Value**: -90
   - **Description**: Specifies the order of the render menu bar relative to other menu bars.

### exts."omni.kit.viewport.menubar.render".shadingMode
   - **Default Value**: "default"
   - **Description**: Sets the default shading mode in the render settings.

### exts."omni.kit.viewport.menubar.render".lightingMode
   - **Default Value**: "default"
   - **Description**: Sets the default lighting mode in the render settings.

### exts."omni.kit.viewport.menubar.render".materialMode
   - **Default Value**: "default"
   - **Description**: Sets the default material mode in the render settings.

### exts."omni.kit.viewport.menubar.render".autoManage.enabledList
   - **Default Value**: "rtx,index,iray,pxr"
   - **Description**: Specifies the list of renderers to manage automatically.

### exts."omni.kit.viewport.menubar.render".autoManage.canRemove
   - **Default Value**: true
   - **Description**: Allows automatic removal of items from the menu when the extension is not loaded.
