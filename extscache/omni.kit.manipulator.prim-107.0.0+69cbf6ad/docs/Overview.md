# Overview
This is a bundle extension which contains "omni.kit.manipulator.prim.core", "omni.kit.manipulator.prim.usd" and
"omni.kit.manipulator.prim.fabric". It provides support for kit prim manipulator that works on both USD and Fabric backend.
