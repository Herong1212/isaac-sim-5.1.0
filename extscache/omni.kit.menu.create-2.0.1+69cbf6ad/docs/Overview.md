# Overview
The `omni.kit.menu.create` extension enhances Omniverse Kit's menu system by adding functionality to create various types of USD primitives, such as shapes, lights, audio sources, cameras, and more. It provides a class `CreateMenuExtension` that dynamically builds a 'Create' menu and handles custom actions for creating items with specific attributes or settings.

## General Use Case
This extension allows users to create USD primitives such as shapes, lights, audio sources, and cameras directly from Omniverse Kit's menu. It provides a convenient way to add new elements to a scene with specific settings, enhancing the user experience for content creation within the Omniverse Kit SDK.
