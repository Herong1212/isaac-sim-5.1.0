omni.flowusd
#################

NVIDIA Flow is a real-time sparse voxel fluid simulation. It includes a combustion model for the creation of fire and smoke effects.

This extension implements interaction between NVIDIA Flow and USD. When combined with the Omniverse RTX Renderer, it enables real-time fluid simulation of fire and smoke. This extension also provides UI for the creation and editing of Flow prims.
