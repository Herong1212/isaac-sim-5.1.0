# omni.flowusd

## Introduction

NVIDIA Flow is a realtime sparse voxel fluid simulation. It includes a combustion model for the creation of fire and smoke effects.

## This extension

This extension implements interaction between NVIDIA Flow and USD. When combined with the Omniverse RTX Renderer, it enables real time fluid simulation of fire and smoke. This extension also provides UI for the creation and editing of Flow prims.

For more information on using this extension, see the online documentation:
https://docs.omniverse.nvidia.com/app_create/prod_extensions/ext_fluid-dynamics.html
