# Overview
This extension provides a comprehensive user interface for managing and interacting with extensions in Omniverse Kit applications. It includes functionalities to list, select, view, and edit extensions, as well as manage settings related to extension paths and registries. The extension offers several key features such as enabling/disabling extensions, viewing detailed information, handling dependencies, and exporting/importing extensions. It also includes a custom status bar and a widget to display extension graphs.

## General Use Case
Users can use this extension to manage extensions within Omniverse Kit applications. They can enable or disable extensions, view detailed information & dependencies, export/import extensions, and manage extension paths and registries. The extension provides a user-friendly interface for these operations, including a custom status bar and graph visualization tools.
