# Settings

## Settings Provided by the Extension
### exts."omni.kit.viewport.menubar.display".visible
   - **Default Value**: true
   - **Description**: Controls the visibility of the display settings in the viewport menu bar.

### exts."omni.kit.viewport.menubar.display".order
   - **Default Value**: -80
   - **Description**: Determines the order in which the display settings appear in the viewport menu bar.

### exts."omni.kit.viewport.menubar.display".showByType.exclude_list
   - **Default Value**: ["Skeletons"]
   - **Description**: Defines a list of types to exclude from the 'Show By Type' category in the display settings menu.
