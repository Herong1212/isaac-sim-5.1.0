# Overview

This extension is an aggregator of the set of extensions required for basic Action Graph use.
Action Graphs are a subset of OmniGraph that control execution flow through event triggers.
Loading this bundle extension is a convenient way to load all of the extensions required to use the OmniGraph
Action Graphs. There is no new functionality added by this bundle over and above what is provided by
loading each of the extensions individually.

## Extensions Loaded

- {ref}`omni.graph<ext_omni_graph>`
- {ref}`omni.graph.action<ext_omni_graph_action>`

- {ref}`omni.graph.ui<ext_omni_graph_ui>`
