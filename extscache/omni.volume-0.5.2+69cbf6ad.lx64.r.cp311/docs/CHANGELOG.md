# Changelog

This document records all notable changes to the **omni.volume** extension.

The format is based on [Keep a Changelog](https://keepachangelog.com). The project adheres to [Semantic Versioning](https://semver.org).

## [Unreleased]

## [0.5.2] - 2024-10-11
### Added
- Python 3.10 and Python 3.11 bindings for OpenVDB and NanoVDB

## [0.5.1] - 2024-10-08
### Removed
- Python OpenVDB bindings

## [0.5.0] - 2023-11-16
### Changed
- Register volume asset type when extension is loaded

## [0.4.0] - 2023-10-23
### Removed
- Refactored LoadVDB and SaveVDB nodes to separate extension to remove OmniGraph dependency

## [0.3.0] - 2023-06-27
### Fixed
- Refactored OmniGraph documentation to point to locally generated files
### Added
- Documentation pages to house the API and OmniGraph node definitions

## [0.2.0] - 2023-06-26
### Fixed
- Refactored OmniGraph documentation to point to locally generated files
### Added
- Documentation pages to house the API and OmniGraph node definitions

## [0.1.0] - 2023-06-22
### Initial Version
- Started changelog
