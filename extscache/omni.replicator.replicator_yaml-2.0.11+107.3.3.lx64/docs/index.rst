omni.replicator.replicator_yaml
###############################

Replicator YAML is a low-code way to access `NVIDIA Omniverse Replicator <https://developer.nvidia.com/omniverse/replicator>`_
to easily build custom synthetic data generation (SDG) tools and pipelines.

You can find example YAML files on our `GitHub repository. <https://github.com/NVIDIA-Omniverse/synthetic-data-examples/tree/main/omni.replicator_yaml>`_
