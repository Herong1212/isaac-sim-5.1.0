# Settings

## Settings Used by the Extension but Provided by Another Extension
### /persistent/app/newStage/defaultTemplate
   - **Description**: Name of the default new stage template.

### /persistent/app/stage/defaultPrimName
   - **Description**: Default primary prim name for the stage, which is used during stage creation.

### /persistent/app/stage/upAxis
   - **Description**: Up axis setting for the stage, which is used to determine the orientation of the stage's up direction.

### /persistent/app/stage/timeCodesPerSecond
   - **Description**: Time codes per second setting for the stage, which affects the timing for animations.

### /persistent/app/stage/timeCodeRange
   - **Description**: Time code range for the stage, setting the start and end time codes for playback.
