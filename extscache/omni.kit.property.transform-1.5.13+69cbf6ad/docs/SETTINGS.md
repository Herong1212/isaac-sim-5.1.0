# Settings

## Settings Used by the Extension but Provided by Another Extension
### /persistent/app/primCreation/DefaultXformOpPrecision
   - **Description**: The default precision setting for transform operations when creating new prims.

### /persistent/app/primCreation/DefaultRotationOrder
   - **Description**: The default rotation order for rotate operations when creating new prims.

### /persistent/app/transform/operation
   - **Description**: Specifies the current transform operation being performed, such as move, rotate, or scale.

### /persistent/app/transform/moveMode
   - **Description**: Determines whether the move operation is applied in global or local space.

### /persistent/app/transform/rotateMode
   - **Description**: Determines whether the rotate operation is applied in global or local space.

### /persistent/app/uiSettings/DisplayOrientAsRotate
   - **Description**: Controls whether the orient attribute is displayed as euler angles or as a quaternion.

### /app/transform/operation
   - **Description**: Represents the active transform operation, like translate, rotate, or scale, for the selected prim.

### /app/transform/moveMode
   - **Description**: Indicates the mode for move operations, which can be either global or local.

### /app/transform/rotateMode
   - **Description**: Indicates the mode for rotate operations, which can be either global or local.
