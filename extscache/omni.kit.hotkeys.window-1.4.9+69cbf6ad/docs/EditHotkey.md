# Edit Hotkey

Select or mouse hover a row will show ![](edit.png). Click to show the edit bar.

![](edit_hotkey_widgets.png)

- Press keyboard to change key binding
- Click ![](trigger.png) to change trigger option: On Press or On Release
- Click ![](save.png) to save changes and exit, including key binding and trigger option
- Click ![](cancel.png) to exit without change
