# Settings

## Settings Provided by the Extension

### `persistent.exts."omni.kit.manipulator.transform".manipulator.freeRotationType`
- **Default Value**: `"Clamped"`
- **Description**: Determines the behavior of free rotation, allowing it to be clamped at the edge or continuous beyond the sphere edge.

### `persistent.exts."omni.kit.manipulator.transform".manipulator.freeRotationEnabled`
- **Default Value**: `true`
- **Description**: Enables or disables free rotation for the manipulator.

### `persistent.exts."omni.kit.manipulator.transform".manipulator.scaleMultiplier`
- **Default Value**: `1.4`
- **Description**: Sets the scale multiplier for the manipulator, affecting its visual representation size.

### `persistent.exts."omni.kit.manipulator.transform".manipulator.intersectionThickness`
- **Default Value**: `10`
- **Description**: Specifies the intersection thickness for the manipulator, affecting hit detection for interaction.

### `persistent.exts."omni.kit.manipulator.transform".tools.defaultCollapsed`
- **Default Value**: `true`
- **Description**: Indicates whether the toolbar should be collapsed by default.

### `persistent.exts."omni.kit.manipulator.transform".manipulator.omniScaleDirection`
- **Default Value**: `"XY"`
- **Description**: Configures the direction in which omni-scale can be performed (e.g., "X", "Y" or "XY").
