# omni.kit.window.status_bar:

Omniverse Kit Status Bar

# Settings

## Settings Provided by the Extension

### `"/app/hydraEngine/skipStatusBarIdle"`
- Default Value: `false`
- Description: Skips updating the status bar when the hydra engine is idle.

### `"/app/hydraEngine/waitIdle"`
- Default Value: `false`
- Description: Force the hydra engine loops to wait after every frame for the GPU to go idle.

### `"/app/hydraEngine/waitMs"`
- Default Value: `20`
- Description: How long to wait for the GPU to go idle after each frame.
