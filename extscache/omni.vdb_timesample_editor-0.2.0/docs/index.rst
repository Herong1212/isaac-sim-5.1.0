omni.vdb_timesample_editor
##################################

The time sample editor is a tool generically useful for USD time sample animation of asset paths. The most common use is to play back texture or VDB sequences.

`Video Tutorial <https://www.nvidia.com/en-us/video/?kid=1_w3p17547>`_ on adding animated textures to MDL.
