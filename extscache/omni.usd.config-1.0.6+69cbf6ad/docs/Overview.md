# Overview
The `omni.usd.config` extension is designed to configure various USD (Universal Scene Description) environment settings for Omniverse Kit applications. The extension primarily works by setting environment variables that influence the behavior of USD within the application.


## General Use Case
The extension is used internally by the Omniverse Kit to configure the USD environment upon startup. This configuration is essential for developers and users who work with USD in the Omniverse Kit environment, as it provides a pre-configured setup that adheres to best practices and the specific needs of Omniverse applications.
