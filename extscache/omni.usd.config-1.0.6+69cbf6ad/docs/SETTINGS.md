# Settings

## Settings Provided by the Extension
### usd.enableNestedGprims
   - **Default Value**: true
   - **Description**: Enables imaging refresh for nested gprims, which is necessary for light gizmos.

### usd.disableCameraAdapter
   - **Default Value**: false
   - **Description**: Disables UsdImaging camera support when set.
