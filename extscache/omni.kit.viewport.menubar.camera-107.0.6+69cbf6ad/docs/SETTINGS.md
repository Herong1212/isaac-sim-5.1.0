# Settings

## Settings Provided by the Extension
### exts."omni.kit.viewport.menubar.camera".visible
   - **Default Value**: true
   - **Description**: Determines if the camera menu and settings are visible in the viewport menu bar.

### exts."omni.kit.viewport.menubar.camera".order
   - **Default Value**: -10
   - **Description**: Specifies the order of the camera menu item in the viewport menu bar.

### exts."omni.kit.viewport.menubar.camera".expand
   - **Default Value**: true
   - **Description**: Controls whether the camera settings are expanded or collapsed by default.

### exts."omni.kit.viewport.menubar.camera".showAutoExposure
   - **Default Value**: true
   - **Description**: Toggles the visibility of the auto-exposure setting in the camera menu.

### exts."omni.kit.viewport.menubar.camera".primQuery.useUsdRt
   - **Default Value**: true
   - **Description**: Configures the camera menu to use UsdRt for prim-type queries when available.

### exts."omni.kit.viewport.menubar.camera".filters
   - **Default Value**: ["/Viewport_Waypoints", "/Viewport_Markups"]
   - **Description**: List of camera path filters that determine which cameras are not displayed in the menu bar.
