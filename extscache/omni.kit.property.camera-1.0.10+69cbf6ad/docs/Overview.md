# Overview
The `omni.kit.property.camera` module offers a specialized widget for editing camera schema attributes within USD stages in the Omniverse Kit environment. It is designed to enhance the camera properties interface, allowing users to customize and extend camera attributes for more detailed and flexible camera configurations. This includes settings like projection types, sensor models, and fisheye lens configurations.

## General Use Case
The `CameraSchemaAttributesWidget` can be used by Omniverse Kit users to modify and define a range of camera-related properties directly within the simulation environment, facilitating advanced scene simulation and rendering with varied camera settings.
