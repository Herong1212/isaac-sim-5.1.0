# Changelog

This document records all notable changes to the **omni.materialx.libs** extension.

The format is based on [Keep a Changelog](https://keepachangelog.com). The project adheres to [Semantic Versioning](https://semver.org).

## [1.0.7] - 2025-01-08
### Changed
- Removed `openpbr` dependency as it was integrated into MaterialX
- Updated tests

## [1.0.6] - 2024-10-18
### Added
- Explicit MaterialX python bindings test

## [1.0.5] - 2024-10-08
### Changed
- OMPE-24532: disable Python code coverage testing.

## [1.0.4] - 2024-06-11
### Changed
- Removed unused symlink.
- OpenPBR v0.4.0

## [1.0.3] - 2024-04-17
### Added
- Add documentation.

## [1.0.2] - 2024-04-12
### Added
- Install OpenPbr libs.

## [1.0.1] - 2024-01-20
### Added
- Renamed from omni.mtlx
- Install MaterialX Python libs + all other MaterialX dll's/dso's.

## [1.0.0] - 2022-09-05
### Added
- Set the MaterialX Standard Library Search Path using a function of this extension.
- Add a test to check the Search Path setup.
- Add rendering tests for RTX Interactive and Iray.

## [0.1.0] - 2022-09-05
### Added
- Initial extension. MaterialX Libraries, required at run-time when MaterialX support is enabled.
