# Overview
The Omniverse MaterialX Libraries extension provides access to the MaterialX libraries required at runtime in Omniverse.  
This includes the OpenPBR implementation in MaterialX.

More information can be found at:
- [MaterialX](https://materialx.org/)
- [OpenPBR](https://github.com/AcademySoftwareFoundation/OpenPBR)
