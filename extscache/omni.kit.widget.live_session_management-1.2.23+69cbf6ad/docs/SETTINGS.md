# Settings

## Settings Provided by the Extension
### exts."omni.kit.widget.live_session_management".session_list_select
   - **Default Value**: LastSession
   - **Description**: Determines which session is selected by default in the live session list, allowing the user to choose between a default session or the last session used.

### exts."omni.kit.widget.live_session_management".quick_join_enabled
   - **Default Value**: True
   - **Description**: Enables the quick join feature that automatically creates and joins a default session without displaying any dialogs.

### exts."omni.kit.widget.live_session_management".viewer_only_mode
   - **Default Value**: False
   - **Description**: Toggles the viewer-only mode which, when enabled, automatically reloads the stage and bypasses dialog prompts when joining or creating live sessions.
