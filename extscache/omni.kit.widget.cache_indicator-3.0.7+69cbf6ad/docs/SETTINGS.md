# Settings

## Settings Provided by the Extension
### exts."omni.kit.widget.cache_indicator".pck_install_path
   - **Default Value**: 
   - **Description**: Specifies the installation path for cache packages and is used to determine the local folder for installed packages.

### exts."omni.kit.widget.cache_indicator".check_updates
   - **Default Value**: True
   - **Description**: Determines whether the extension should check for updated versions to hub_workstation_cache.

### exts."omni.kit.widget.cache_indicator".ngc_api
   - **Default Value**: https://api.ngc.nvidia.com/v2
   - **Description**: Sets the endpoint URL for the NGC API used to to get hub_workstation_cache.

### exts."omni.kit.widget.cache_indicator".ngc_api_key
   - **Default Value**: 
   - **Description**: Provides the API key for authenticating requests to the NGC API when accessing protected resources.

### exts."omni.kit.widget.cache_indicator".ngc_resource
   - **Default Value**: hub_workstation_cache
   - **Description**: Defines the NGC resource name which is used to look up hub versions and related files.

### exts."omni.kit.widget.cache_indicator".ngc_team

   - **Description**: Specifies the NGC Team name that contains hub_workstation_cache.

### exts."omni.kit.widget.cache_indicator".ngc_org
   - **Default Value**: nvidia
   - **Description**: Indicates the NGC Organization that contains hub_workstation_cache.
