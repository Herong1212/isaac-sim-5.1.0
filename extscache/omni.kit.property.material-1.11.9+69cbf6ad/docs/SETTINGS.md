# Settings

## Settings Provided by the Extension
### ext."omni.kit.property.material".enableAdapter
   - **Default Value**: false
   - **Description**: Determines if the material adapter is enabled for drag and drop operations.

## Settings Used by the Extension but Provided by Another Extension
### /persistent/app/material/dragDropMaterialPath
   - **Description**: Controls whether the path for materials dragged and dropped onto a property widget is stored as absolute or relative.

### /persistent/app/window/uiStyle
   - **Description**: Determines the UI style of the property window based on the application's persistent settings.

### /persistent/app/rendering/whiteModeExceptions
   - **Description**: Specifies which materials should be exempt from the 'white mode' rendering setting, where non-emissive materials are rendered as white.
