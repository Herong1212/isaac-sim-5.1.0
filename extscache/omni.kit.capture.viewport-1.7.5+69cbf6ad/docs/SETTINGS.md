# Settings

## Settings Provided by the Extension

### exts."omni.kit.capture.viewport".renderProduct.waitFrames
- **Default Value**: 1
- **Description**: Specifies the number of frames the system waits after finishing a render product capture to allow post‐processing (such as reshade updates) to complete.

## Settings Used by the Extension but Provided by Another Extension

### /exts/omni.videoencoding/bitrate
- **Description**: Specifies the bitrate value used for MP4 video encoding during the capture process.

### /exts/omni.videoencoding/iframeinterval
- **Description**: Determines the interval between I-frames when encoding MP4 videos.

### /exts/omni.videoencoding/preset
- **Description**: Provides a preset configuration that controls various encoding parameters for MP4 output.

### /exts/omni.videoencoding/profile
- **Description**: Indicates the encoding profile applied during MP4 video generation.

### /exts/omni.videoencoding/rcMode
- **Description**: Defines the rate control mode used in the MP4 encoding process.

### /exts/omni.videoencoding/rcTargetQuality
- **Description**: Sets the target quality level for rate control during MP4 encoding.

### /exts/omni.videoencoding/videoFullRangeFlag
- **Description**: Determines whether the video encoding will use the full range flag for color and brightness values.
