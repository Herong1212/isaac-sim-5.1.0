Omni PhysX Vehicle
###################################

The omni.physx.vehicle extension adds authoring support and utilities for vehicles that are based on the PhysX Vehicle SDK. Just like other PhysX objects in Omniverse Kit, vehicles are represented in USD using the type definitions in PhysxSchema. Even though vehicles are created as part of the omni.physx extension, tools and other features are available through the omni.physx.vehicle extension only. This includes default input device support to drive a vehicle, special property views, a vehicle creation wizard, samples and C++ as well as Python APIs with helper functions.
