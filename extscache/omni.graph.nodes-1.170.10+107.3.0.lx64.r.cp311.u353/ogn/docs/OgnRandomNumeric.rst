Random Numeric
==============

.. <description>

Generates a random numeric value in a range, using a uniform distribution. The range is specified with two inputs: "Minimum" and "Maximum". These inputs can be numbers, vectors, tuples or arrays of these. If one input has a higher dimension than the other, then the input with the lower dimension will be repeated to match the dimension of the other input (broadcasting).

.. </description>
