Arcsine
=======

.. <description>

Compute the arcsine (in degrees) of a scalar, array of scalars, vector, or array of vectors; in the latter three cases the arcsine operator is applied to every single scalar element in the corresponding structures. Note that each scalar element must lie in the domain [-1, 1], otherwise the computation will fail.

.. </description>
