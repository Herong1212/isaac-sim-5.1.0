# Overview

This extension loads Omniverse USD Resolver plug-in for resolving assets from the following protocols:

- omniverse://, omni:// (Nucleus)
- http://, https:// (Web, with extra support for S3)
- file:// (File URI)
- POSIX (Linux file paths)
- Windows (Windows file paths)

For detailed information, please refer to [Omniverse USD Resolver](https://docs.omniverse.nvidia.com/kit/docs/usd_resolver/latest/).
