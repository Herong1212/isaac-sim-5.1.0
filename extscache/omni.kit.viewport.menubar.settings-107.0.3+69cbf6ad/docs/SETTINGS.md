# Settings

## Settings Provided by the Extension
### exts."omni.kit.viewport.menubar.settings".visible
   - **Default Value**: true
   - **Description**: Controls the visibility of the viewport settings in the menu bar.

### exts."omni.kit.viewport.menubar.settings".order
   - **Default Value**: -100
   - **Description**: Determines the order in which the viewport settings appear in the menu bar.

### exts."omni.kit.viewport.menubar.settings".show.camera.clamping
   - **Default Value**: true
   - **Description**: Toggles the camera clamping feature within the viewport settings.

### app.viewport.ui.minBrightness
   - **Default Value**: 0.5
   - **Description**: Sets the minimum brightness level for the viewport UI.

### app.viewport.ui.maxBrightness
   - **Default Value**: 1.0
   - **Description**: Sets the maximum brightness level for the viewport UI.
