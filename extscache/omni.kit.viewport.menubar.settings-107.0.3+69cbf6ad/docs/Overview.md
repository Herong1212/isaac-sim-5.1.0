# Overview
The `omni.kit.viewport.menubar.settings` extension provides a comprehensive set of settings for customizing the viewport experience in Omniverse Kit. It allows users to adjust various viewport parameters, such as navigation speed, selection color, grid settings, gizmo settings, and more. Additionally, it offers functionality to manage custom render resolutions and supports saving custom resolutions for later use.

## General Use Case
Users can use this extension to customize their viewport settings within the Omniverse Kit environment. They can modify navigation controls, change colors for selections, bounding boxes, and grids, adjust gizmo behavior, and manage rendering resolutions. The extension provides a user-friendly interface to save custom resolutions and access various viewport settings, making it easier to tailor the viewport to specific needs or preferences.
