# Actions in omni.kit.selection

| ID             | Display Name             | Description                                                                         |
|:---------------|:-------------------------|:------------------------------------------------------------------------------------|
| HideUnselected | Select->Hide Unselected  | Hide Unselected Prims                                                               |
| UnhideAllPrims | Select->Unhide All Prims | Unhide All Prims                                                                    |
| all            | Select->All              | Select all prims.                                                                   |
| hierarchy      | Select->Hierarchy        | Select the hierachies of all currently selected prims.                              |
| invert         | Select->Invert           | Deselect all currently unselected prims, and select all currently unselected prims. |
| leaf           | Select->Leaf             | Select the leafs of all currently selected prims.                                   |
| none           | Select->None             | Deselect all prims.                                                                 |
| parent         | Select->Parent           | Select the parents of all currently selected prims.                                 |
| similar        | Select->Similar          | Select prims of the same type as any currently selected prim.                       |
