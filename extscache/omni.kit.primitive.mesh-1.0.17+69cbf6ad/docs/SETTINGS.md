# Settings

## Settings Used by the Extension but Provided by Another Extension
### /persistent/app/primCreation/DefaultXformOpType
   - **Description**: Specifies the default transformation operation type for mesh primitives created in the USD stage.

### /persistent/app/primCreation/DefaultRotationOrder
   - **Description**: Determines the default rotation order for the transformation operations applied to the newly created mesh primitives.

### /persistent/app/primCreation/DefaultXformOpPrecision
   - **Description**: Sets the precision (float or double) for the transformation operations applied to the new mesh primitives.
