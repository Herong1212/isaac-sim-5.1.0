# Changelog
This document records all notable changes to ``omni.kit.search_core`` extension.

## [1.0.8] - 2025-04-15
### Changed
- Updated documentation with AI agent.

## [1.0.7] - 2025-01-06
### Added
- Update usage of 'is_service_available'.

## [1.0.6] - 2024-11-06
### Added
- OMPE-25667: Update public API.

## [1.0.5] - 2023-10-17
### Added
- Added tests to increase code coverage.

## [1.0.4] - 2023-06-14
### Added
- Added public API to get all supported search engine names by given server folder.

## [1.0.3] - 2023-03-27
### Added
- Added public API to subscribe to search engines changed event and added related test.

### Removed
- Removed dependency on omni.kit.test

## [1.0.1] - 2022-03-07
### Added
- Added a search lifetime object that can be used for callbacks after search is done to indicate progress.

## [1.0.0] - 2020-10-05
### Added
- Initial model and registry
