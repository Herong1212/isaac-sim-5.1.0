# Settings

## Settings Provided by the Extension
### exts."omni.kit.window.content_browser".timeout
   - **Default Value**: 10.0
   - **Description**: Time-out value for the content browser operations, unit is second.

### exts."omni.kit.window.content_browser".show_grid_view
   - **Default Value**: false
   - **Description**: Determines if the content browser should display items in grid view by default.

### exts."omni.kit.window.content_browser".enable_checkpoints
   - **Default Value**: true
   - **Description**: Enables or disables the checkpoint feature in the content browser.

### exts."omni.kit.window.content_browser".enable_timestamp
   - **Default Value**: false
   - **Description**: Toggles the visibility of timestamps on items within the content browser.

### exts."omni.kit.window.content_browser".show_only_collections
   - **Default Value**: ["bookmarks", "omniverse", "my-computer"]
   - **Description**: Filters the content browser to only show specified collections by default.

### exts."omni.kit.window.content_browser".show_download_menuitem
   - **Default Value**: true
   - **Description**: Controls the visibility of the download option in the content browser's context menu.
