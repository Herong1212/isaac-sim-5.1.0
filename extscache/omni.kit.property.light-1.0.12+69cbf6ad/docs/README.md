# omni.kit.property.light

## Introduction

Property window extensions are for viewing and editing Usd Prim Attributes

## This extension supports editing of these Usd Types;

- UsdLux.CylinderLight
- UsdLux.DiskLight
- UsdLux.DistantLight
- UsdLux.DomeLight
- UsdLux.GeometryLight
- UsdLux.RectLight
- UsdLux.SphereLight
- UsdLux.ShapingAPI
- UsdLux.ShadowAPI
- UsdLux.LightFilter
- UsdLux.PortalLight

### and supports editing of these Usd APIs;

- UsdLux.ListAPI
